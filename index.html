Store dataset configuration in a control table so one reusable ADF framework can ingest many sources.

Bronze

Land immutable source data in ADLS with ingestion timestamps and source lineage.

Silver

Use Databricks/PySpark for type enforcement, deduplication, schema handling and Delta MERGE logic.

Gold

Publish dimensional and business-ready tables for Synapse or BI consumers with auditability across layers.
